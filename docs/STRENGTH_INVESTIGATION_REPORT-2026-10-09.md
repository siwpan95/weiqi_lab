# 引擎强度勘察 · 收口报告（2026-10-09）

> 本文件把本批（2026-10-08~09）所有结论按 **确认级 / 趋势 / 已更正 / 已撤回** 四档归类，
> 作为 `docs/ENGINE_STRENGTH.md` 与 `docs/TIER3_LEARNING.md` 的决策层摘要。
> 所有数字均来自本仓实测；统计纪律见 §0。

---

## 0. 协议与统计纪律（判读前提）

- **基础协议**：9 路 · 150 playouts/手 · 黑白对调自对弈（`tournament/ab_prior.mjs`）；大样本项扩到 300~600 局。
- **显著性**：两比例 z 检验（双尾）；多参数扫描用 **Bonferroni** 校正（α' = α / 项数）。
- **复现纪律**：所有"显著但效应量小"的结论必须做**确认实验**（新 seed 重跑）；方向性结论必须**两侧同等复核**（见 §2/§3 的 pbias 教训）。
- **机制先于效应**：参数疑似无效时，先用 **指纹检验**（同 `(局面, playouts, seed, profile)` 下 `[着法, 访问数, 胜率]` 三元组是否逐位不同）证机制，再谈强度。
- **传递性检验定位**：共用同一 B 的多个实验可反推隐含胜率，用于**发现矛盾**（触发直接测量），**不可用于定值**（复合噪声 + 自对弈不严格满足 Bradley-Terry）。

## 1. 确认级结论（Confirmed）

> 这些结论经**直接测量 + 确认实验（新 seed）**双重支撑，可靠。

| # | 结论 | 关键证据 |
|---|---|---|
| C1 | **推荐配置 `{probe_k:3, pw_c:0.5, pw_min:6}` 对原始默认显著更强且更快** | 两次各 300 局 **72.3% / 70.7%**，合并 600 局 **71.5%（p<0.0001）**；每手 **93→25~29 ms（×3.2）** |
| C2 | **惰性探测 `probe_k=3`：更快且更强**（非原以为的"免费提速"） | 300 局 54.7% vs 45.3%（p=0.0222）→ **400 局 58.5% vs 41.5%（p<0.0001）确认** |
| C3 | **渐进加宽 `pw_c=0.5 / pw_min=6`：唯一过校正门槛的搜索改进** | 300 局 **59.3% vs 40.7%（p<0.0001）**；邻域两侧 `pw_c=1.0`→40.0%、`pw_min=4`→36.7% **显著更差** → 落于已验证平台中部 |
| C4 | **零分配化（scratch 化）：19 路 70× 提速，行为逐位不变** | 19 路 genmove 5940ms→81ms；70 快照 0 差异；纯实现优化，跨语言可比性不受影响 |
| C5 | **RAVE 在参考实现与 6 语言移植中恒为 no-op**（根层退化为恒等） | 代数证明（β 被完全消去）+ 4/4 指纹恒等；已实现 `amaf_full` 修复，但 600 局（两组各 300）强度**中性**且不带来预期聚焦 → 保持默认关闭、不为强度移植 |
| C6 | **包级收益（P0+P1 合计）：强度 +44.6pp、速度 ×3.2** | 见 C1/C2/C3 的合成口径 |
| C7 | **CNN 前向先验"机制"有效，但 9 路弱教师先验是负资产** | 19 路人类局面：选点精确吻合 0%→29.2%、邻近 4.2%→62.5%（p<0.0001）；9 路弱引擎教师先验 **−28.8pp（p=0.0001）** → 先验质量上限 = 教师质量上限 |
| C8 | **对称帧修正（语义缺陷修复）已确认** | 回归测试 8/8；所有模式表 top-1 上修（人类19路 7.25%→21.34%，CNN蒸馏19路 7.33%→22.70% = CNN 88%，9路弱自对弈 4.13%→8.87%） |

**C1+C2+C3 的对照是本书最有说服力的单条证据**：同一协议下，+44.6pp 的改进稳定复现（72.3%→70.7%），+9.4pp 在 300 局被判"更强"、400 局确认——**大效应稳、中效应可复现**；而下方 §3 的 pbias（±4pp）任何样本量都飘忽。

## 4. 已撤回结论（Withdrawn — 曾持方向，被复核推翻后撤销）

> 这些是**最危险的类别**：曾在小样本下"显著"，若只做单侧复核就会留下错误方向。

| # | 曾持结论 | 撤回依据 |
|---|---|---|
| W1 | **pbias 在 9 路有强度收益**（强教师侧 200 局 +7~8pp，合并 p=0.0339；弱教师侧 −11pp，p=0.0278） | 400 局确认 **49.3%** / 复核 **52.0%** → 均未复现；合计 **1700 局 / 4 条件（含 19 路大盘 100 局 52.0%, p=0.5716）全中性**。尤其险在：负侧 p=0.0278 看起来比正侧更"可信"，却是同一噪声 → 若只复核正侧会留下错误方向。**必须两侧同等复核** |
| W2 | **开局方案影响胜负**（Markov / CNN 前向开局更"强"） | 440 局（4 组 ×110）6 对比较 Bonferroni 后最小 p=0.0543，四组无稳健差异 → 棋形结构差异**真实**但胜负**不可分**（被引擎噪声淹没） |

> 注：W1 的**机制层仍有效**（playout 命中率 97.5~99.9%、机制探针 p=0.0389），只是强度不变——这正是"机制有效 ≠ 有效果"，且印证 §5 横向结论。

## 5. 横向结论（本批最重要的综合判断）

1. **搜索侧的红利已经吃完，瓶颈在估值质量。**
2. **只有"算力分配"两类改进带来强度收益**：
   - 少算无用候选（`probe_k=3`，−97% probe）；
   - 把预算集中到有希望的候选（渐进加宽）。
   所有"让每一手更聪明"的改动（LGR / lib2 / pbias / 真 RAVE / 参数微调 13 项）**全部测不出收益**。
3. **诊断**：`±5 点战术分辨力`（playout 终局计分被随机提子主导）意味着叶子估值信息量极低；
   当单次模拟返回值近噪声时，改"用了多少次"起效，改"单次质量"无效——**噪声不被更聪明的选点修复**。
4. **方向重排**：估值质量（价值头 / 死子判定 / 更长 playout）升为第一优先级；搜索侧仅剩转置去重等低收益项，不再投入。

## 6. 方法论收获（本批沉淀，价值不亚于结论）

1. **确认实验不是形式主义**：+44.6pp 复现、+9.4pp 复现、±4pp 消失，同协议下同台对照。
2. **两侧同等复核**：pbias 的 W1 教训——单侧复核会留下错误方向。
3. **参数疑似无效 → 先证机制（指纹检验）再谈效应**：mercy 的 0.15/0.3 同值 69/150 看似死参数，指纹证明生效（聚合巧合）。
4. **传递性检验的定位**：只用于"发现矛盾、触发直接测量"，不可定值。
5. **90 局不足以支撑"无差异"结论**：未检出差异必须标注样本量并尽快复核（K1 教训）。
6. **对称帧类语义缺陷必须有可判定回归测试**：8 旋转合成用例把"抹平"变成 2/8 vs 8/8，铁证。
